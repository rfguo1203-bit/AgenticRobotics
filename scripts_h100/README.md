# H100服务器运行脚本

本目录只保存 **H100服务器环境适配和运行包装脚本**，不承载通用应用逻辑。可以在本目录下面再细分envs、runs等文件夹。

## 职责范围

适合：

- `env.sh`：CUDA、Python、模型、数据、缓存、代理和端口环境变量；
- `setup.sh`：依赖及资产检查、可重复安装入口；
- `run_*.sh`：按顺序启动模型、仿真和 Demo，并执行健康检查；
- `stop_*.sh`：清理本轮启动的服务；
- `collect_logs.sh`：收集配置、日志、退出码和运行产物。

不适合：

- VLM 控制、动作解析和任务状态机；
- PEAR／cuRobo 上游源码副本；
- 机器人规划或成功判据实现；
- 模型权重、数据集、日志、视频、密钥或 Token。

## 使用约定

- 通用入口由开发机维护，本目录脚本只设置环境并调用它。
- 所有机器相关值通过环境变量传入，并提供必要的缺失检查。
- 不提交服务器私有绝对路径；文档示例使用占位符。
- 使用 `set -euo pipefail`，失败返回非零退出码。
- 长任务应有日志、超时、正常启动迹象和清理方式。
- 运行前检查旧进程、端口和 GPU 占用，避免重复启动。
- 每次运行使用独立产物目录，保存 commit、配置和随机种子。

## 热修复与回流

H100服务器通用源码热修复默认最多 3 个文件、增删合计 100 行，只解决一个问题。`scripts_h100/` 的单一职责脚本不计入该预算，但仍不得承载应用逻辑。

所有修改和验证结果使用 `HANDOFF_TEMPLATE.md` 汇总成**一个 Markdown 文件**，包含完整 unified diff。禁止只回传代码片段或不完整的修改说明。

开发机原样应用并推送后，H100服务器才能在用户允许下撤销临时修改并 `git pull`。正式版本需要重新运行相同验证。

详细权限和同步状态见根目录 `AGENTS.md` 与 `AGENTS_H100.md`。
